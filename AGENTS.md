# Работа с LinkRadar

- Начните с `MEMORY.md`, затем `README-SOURCE.md` и соответствующего модуля.
  Актуальная настольная версия имеет приоритет над историей веб-интерфейса.
- Обновляйте `MEMORY.md` и инструкции при изменении поведения, ограничений или проверки.
- Сохраняйте ручной запуск захвата, привязку ping/маршрута к адаптеру,
  ограничение 12 часов, историю пакетов 120 секунд и очистку при закрытии.
- Не подменяйте реальные измерения демонстрационными данными. Промежуточный ICMP
  timeout не доказывает потерю транзитного трафика; ICMP jitter не равен jitter видео.
- Используйте синтетические фикстуры и отдельный временный каталог данных для проверки.
  Не меняйте установленное приложение, работающую службу или пользовательскую базу
  для тестирования без поручения на эти действия.
- Перед коммитом проверяйте состав файлов: исключайте секреты, базы, логи, реальные
  захваты/скриншоты и бинарные сборки. Инструкции пишите в `.md`.
- Проверяйте изменения соразмерно: основной набор
  `python -m unittest discover -s tests -p 'test_*.py'`.
  Безэкранные Qt-тесты можно запускать с `QT_QPA_PLATFORM=offscreen`.
- Stream только читает OBS/vMix/таблицы ОС. Не выводите, не храните и не экспортируйте
  ключи потоков, пароли и параметры SRT; не пишите в OBS/vMix.
- Не заявляйте проверенный запуск Windows или работу на реальном коммутаторе
  на основании одного mock-теста либо сборки на Mac.

- Запись GUI-данных сессии выполняйте через IOQueue, локально и через IPC.
  Экспорт ждёт barrier; cache подтверждает строки только после успешной записи
  и истекает по 12-часовому сроку, а не сбрасывается целиком при 50k.
- Для таблиц/журналов проверяйте клавиатуру, выбранный ключ, чтение и курсор
  во время append/expiry. Потоковые строки Qt обновляйте инкрементально;
  общий helper log_widgets сохраняет selection/visual-line anchor.

- Таймеры скрытых вкладок не должны строить тяжёлые снимки/таблицы, но сроки
  хранения и уже запрошенные команды продолжают обслуживаться. Возврат вкладки
  читает свежие данные; позиция чтения журнала и выделение сохраняются.
- Ручные отчёты получают текущий snapshot, а файлы сохраняются через
  `export_transfer.atomic_write`. Предсказуемые соседние `.tmp` не используйте.
- В осях, подсказках и таблицах форматируйте даты через `time_labels`; дата вне
  диапазона ОС должна показывать «—», а не прерывать Qt paint/data callback.

- При изменении SQL-индексов сохраняйте измерения и атомарный rollback миграции.
  Короткий период и вся 12-часовая история требуют разных планов запроса;
  выигрыш чтения проверяйте вместе с размером индекса и ценой записи.
- Плотные флапы графиков ограничивайте детализацией экрана, сохраняя extrema,
  видимые разрывы и полные raw/hover/TXT. Журнал может содержать многострочные
  ошибки; при TTL удаляйте целые события и освобождайте кэш их подписей.

- Отчёт Stream считайте из единого снимка с обеими границами периода.
  Долгие copy/save выполняйте вне GUI: network_report_job захватывает виджеты
  заранее, worker читает только движки. При закрытии ждите report worker;
  не записывайте clipboard после начала закрытия и освобождайте большой result.

- Геометрию Qt проверяйте с производственными Fusion/STYLE и после стартовых
  layout-таймеров. Большие окна требуют подходящего тестового рабочего стола;
  tests/windows_ci_desktop.py --configure допустим только в одноразовой Windows CI.
  Сохраняйте минимум 900×640 и доступ к справке через шестерёнку; на macOS — нативное меню.
- Windows owner файла не обязан совпадать с TokenUser администратора.
  secure_directory возвращает прежнего владельца; без O: SDDL его не меняет.
  Проверяйте реальные owner/DACL, не POSIX mode. Доверенные владельцы не расширяются ради тестов.
- Фикстуры закрывают окна/БД до удаления TemporaryDirectory даже после assertion.
  Сверку snapshot с живой БД делайте на одном префиксе данных, с нужной синхронизацией.
