## Воспроизведение

```sh
python -m unittest discover -s tests -p 'test_*.py' -v
python tests/integration_local.py
node tests/test_start_stop.js
node tests/test_stream_analysis.js
```

На Windows: `QT_QPA_PLATFORM=windows`. Для геометрии рабочий стол должен помещать требуемые размеры; CI запускает tests/windows_ci_desktop.py --configure только в одноразовой GitHub VM. Скрипт отказывает в изменении экрана вне Windows GitHub Actions; настройки компьютера пользователя не менялись. На macOS без экрана: QT_QPA_PLATFORM=offscreen.

Проверка исходников и нативного Qt на Windows runner не равна проверке опубликованного Windows EXE, Npcap, службы SYSTEM или реального USB/коммутатора. Опубликованные пакеты v2.10.9 этим этапом не заменяются.
