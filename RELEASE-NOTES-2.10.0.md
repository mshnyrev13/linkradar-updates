# LinkRadar 2.10.0 — стабилизация

Локальная версия, пока не опубликована. Установка пользователю и замена рабочей
службы в ходе этой проверки не выполняются.

- Исправлены текущие RTT/jitter при смене масштаба. UI и TXT используют один
  EWMA; средняя абсолютная разница RTT вынесена в mean_delta. Карточки относятся
  к конечному серверу, выбранный hop меняет график.
- Нет свежих проб, ошибка проверки и недоступность цели показаны раздельно.
  Локальные ошибки не выдают себя за PL; ICMP Unreachable — неуспешная проба.
- Таблица маршрута агрегируется SQLite, загружаются только нужные графики.
  Долгий reader не удерживает блокировку writer. В подсказке — фактический
  интервал проб узла и длительность последовательного цикла TTL.
- TXT сохраняется вне GUI и передаётся частями с проверкой SHA-256. Отмена,
  обрыв или ошибка не заменяют существующий файл неполным результатом.
- Исправлен плавающий Connection refused и потеря записи скорости при
  конкурентном IPC. Повтор данных идемпотентен, кэш Graphene подтверждается
  после записи. Невосстановленная ошибка отмечается в UI и TXT.
- Команды и закрытие не блокируют обработку событий GUI. Движок сериализует
  start/resume/clear, учитывает ещё завершающиеся workers. Старый UI snapshot
  не может отменить новую паузу/масштаб. DNS и авторизация IPC ограничены.
- HTTP-тест скорости использует выбранный адаптер без fallback. Смена адаптера
  отменяет тест. DNS остаётся системным; в Auto маршрут выбирает ОС.
- Graphene использует соединение повторно и догружает хвост. LLDP возвращает
  автоматический выбор; при отключении последние данные сохраняются. Частота
  запросов 5 с не ускоряет публикацию исходных метрик.
- Stream: безопасные остановка/перезапуск, отбрасывание прежних результатов,
  свежесть источников, старение истории на паузе, защита от URL-секретов.
- Сохраняются безопасные настройки окна; отсутствующий адаптер не заменяется
  Auto. В выборе серверов доступен шлюз. Журнал открывает GUI и service логи.
- vMix разрешает только чтение `/api` без управляющих query и redirects. OBS после
  паузы сохраняет известные сегменты; разрыв наблюдения отмечается в отчёте.
- Маршрут hostname следует IP последнего ping. Jitter hop учитывает фактическую
  частоту трассировки, а не только заданный интервал конечного ping.
- Добавлены исходные хеши сборки и проверки CI для macOS/Windows. Добавление
  workflow не означает, что он уже выполнялся на Windows.

Замеры, проверка сборки и ограничения — [VALIDATION.md](VALIDATION.md).
Ход нескольких циклов — [STABILITY-WORKLOG.md](STABILITY-WORKLOG.md).

macOS: Apple Silicon, macOS 15+, ad hoc подпись без Developer ID/нотаризации.
Windows: нужен Npcap для захвата/LLDP; исполнение новой версии на Windows и
физическое USB-переподключение требуют отдельной приёмки. ICMP не измеряет
jitter видеопотока и не гарантирует качество трансляции.
