# Функции LinkRadar

[Установка Windows](windows.md) · [Установка macOS](macos.md) · [Stream](stream.md)

## Адаптер, коммутатор и порт

В режиме «Автоматически» используется маршрут ОС. При ручном выборе ping, ICMP-маршрут и HTTP-тест скорости привязываются к адаптеру. При его отключении LinkRadar показывает недоступность и сохраняет выбор. DNS использует системный резолвер.

Коммутатор и порт определяются по объявлениям LLDP/CDP. LLDP имеет приоритет, пока объявление не истечёт. Кнопка ↻ в строке адаптера заново открывает приём. Частота объявлений зависит от коммутатора. Для приёма на Windows нужен Npcap, на macOS требуется доступ к BPF. Графики Graphene доступны при наличии корпоративного доступа к источнику.

## Ping, маршрут и скорость

Введите сервер и нажмите ▶. Пауза сохраняет историю, а запуск с новым сервером начинает новую. Карточки относятся к конечному серверу. Выбор промежуточного узла переключает графики.

Windows ICMP API сообщает RTT целыми миллисекундами. Интерфейс показывает 0 как «<1 мс». ICMP jitter характеризует изменение задержки ответов ICMP. Состояние трансляции смотрите по счётчикам OBS/vMix во вкладке Stream. Потеря ответа промежуточного узла может быть связана с обработкой ICMP на этом узле.

HTTP-тест скорости измеряет фактическую загрузку и отдачу до сервера теста. Смена выбранного адаптера отменяет текущий тест.

## Захват пакетов

Захват включается отдельной кнопкой ▶ и показывает пакеты выбранного адаптера. Пауза сохраняет сессию, Stop завершает её. При следующем запуске после Stop буфер очищается. Последние 120 секунд сохраняются в памяти, в том числе во время паузы. Для просмотра чужого трафика на коммутаторе обычно нужен SPAN или зеркалирование порта.

## Данные и фоновый режим

История измерений хранится до 12 часов. При обычном закрытии LinkRadar останавливает сбор и очищает данные сессии. Сохранённые вручную TXT, настройки и отдельный технический журнал ошибок остаются. Папку экспорта можно выбрать в диалоге сохранения.

Фоновый движок настраивается отдельно. На Windows системная задача выполняется от SYSTEM, а окно подключается через аутентифицированный локальный канал. Установка и обновление описаны в [руководстве Windows](windows.md). Для macOS см. [руководство macOS](macos.md).
