# Повторный кодовый и визуальный аудит LinkRadar 2.10.3

21 октября 2026. Проверка поверх 2.10.2; все прежние изменения сохранены.
Рабочая app, системная служба, пользовательские настройки/база не менялись.
Публикация и установка не выполнялись. Измерительные формулы и интервалы,
привязка адаптера, ручной захват, 12-часовая история и очистка сохранены.

## Подтверждённые находки

| Находка | Исправление и проверка |
| --- | --- |
| Длинный непрерывный ряд Graphene терял заполнение и соединение точек | Прореживание хранило редкие точки, а renderer ошибочно принимал их расстояние за разрыв исходного ряда. `line_samples` передаёт настоящий break-флаг от исходных соседей. На 43 200 постоянных точках покрытие заполнением 0% → 100%; настоящие gaps/None и extrema сохранены. |
| Обрезались старшие цифры шкалы пакетов/ошибок | Динамический отступ по font metrics и подписи, которые помещаются в доступную ширину. Например, прежняя шкала могла показывать хвост «753,07» вместо «9469753,07». Точный hover не округляется по шкале. |
| Перерисовка и hover многократно сканировали длинную историю | Общая `CachedPlot`: одна DPI-aware поверхность на график, курсор рисуется поверх. Кэш сбрасывается на новых данных, размере, шрифте, DPI, сообщении. Точные hover-точки ищутся бинарным поиском в исходном ряду. |
| Локальная ошибка проверки выглядела как потерянный ICMP-ответ | На RTT — отдельный оранжевый пунктир и подсказка «локальная ошибка проверки». ICMP Unreachable подписан «цель недоступна». Числовой PL и история не менялись. |
| Graphene каждые 5 с сбрасывала выделение текста/курсор источника | Неизменные host/port не переприсваиваются. Регрессия сохраняет выделение коммутатора и позицию курсора порта. |
| Узкая легенда Stream могла теснить заголовок; временные подписи пересекались | При нехватке ширины легенда получает отдельную строку; узкая временная ось — два деления. Само расположение блоков и кнопки сохранены. |
| Крайнее конечное число могло переполнить расчёт масштаба | Headroom и округление шкалы остаются конечными даже для 1,7e308. Защитная синтетическая проверка, не утверждение о таких реальных показаниях. |

Самплинг используется только для рисунка. История, экспорт, статистика и точные
значения по наведению остаются исходными. Stream получает отсортированную копию
ряда для рисования; исходный ряд не переставляется и не прореживается.

## Производительность

Один процесс на текущем Mac, Qt offscreen, фиксированные размеры. Это
синтетические измерения, не оценка загрузки пользовательской рабочей сессии.

| Операция, 43 200 точек | До | После |
| --- | ---: | ---: |
| Повторный redraw Graphene 320×180 | 32,0768 мс | 0,0098 мс |
| Hover Graphene | 3,6023 мс | 0,2241 мс |
| Повторный redraw Stream 400×180 | 22,6038 мс | 0,0115 мс |
| Новые данные + paint Stream | 22,5248 мс | 17,1400 мс |
| Hover Stream | 1,8429 мс | 0,1319 мс |

Почти нулевая стоимость повторного redraw относится к готовому изображению,
а не к обработке нового ряда. Слияние двух проходов sampler уменьшило стоимость
свежих данных без потери разрывов и экстремумов.

45-секундная интерактивная нагрузка: окно 1100×700, три Graphene-графика по
8641 точке и три Stream-графика по 43 201, hover 30 Гц, свежие Stream данные
раз в секунду / Graphene раз в 5 с:

| Показатель | До | После |
| --- | ---: | ---: |
| CPU, эквивалент одного ядра | 132,39% | 12,57% |
| Process CPU | 59,615 с | 5,655 с |
| Heartbeat P99 | 109,206 мс | 75,318 мс |
| Максимальный heartbeat gap | 117,998 мс | 99,158 мс |
| Peak RSS | 149 651 456 байт | 155 353 088 байт |

CPU снизился на 90,51% в этом сценарии. Цена кэша — около 5,7 МБ дополнительного
пика памяти. Это не доказательство отсутствия длительного роста: сценарий
короткий. Новое полное 12-часовое окно всё ещё требует сканирования и может
дать паузу интерфейса около 100 мс при одновременном обновлении шести графиков.
Длительный soak и замеры памяти 2.10.0/2.10.2 не выдаются за новый длительный тест.

## Визуальная и функциональная проверка

- Три новые поведенческие регрессии воспроизведены до исправления; четвёртая
  проверка прокрутки Stream прошла и до него. Предположение о сбросе прокрутки
  в этом сценарии не подтвердилось, соответствующая логика не менялась.
- 13 новых проверок: заполнение, реальные gaps/extrema, шкалы, точный поиск,
  выделение текста, локальные ошибки, конечные числа, смена размера/шрифта/DPI,
  узкая легенда и отсутствие перестановки исходных точек.
- Финальный набор: **319 тестов OK, 11 платформенных пропусков, 31,271 с**.
- 8 синтетических состояний в окнах 900×640, 1100×760, 1440×960: точные размеры,
  элементы в границах. Дополнительно те же состояния с масштабом 150%.
- Скриншоты, замеры и воспроизведение — [round2/README.md](https://github.com/mshnyrev13/vcs-network-watch).

## Границы

Проверки Windows, чистого Mac/другого пользователя, настоящей установки,
реального эфира и всех аппаратных адаптеров этим этапом не выполнены.
Developer ID/нотаризации и Windows publisher signature нет. Изменения безопасности
2.10.1 и скорости 2.10.2 включены; повторные нагрузочные download/upload и полный
внешний аудит зависимостей без новой причины не запускались.
Приложение не объявляется безошибочным; результаты относятся к проверенным путям.
