# LinkRadar 2.10.10

- Исходники, тесты, выпуски и канал обновлений объединены в публичном linkradar-updates.
- Исправлена минимальная высота Windows: окно 900×640, справка через шестерёнку.
- Исправлены Windows CI: фактические owner/DACL, освобождение Qt/SQLite, размеры тестового рабочего стола.
- Устранена гонка в проверке маршрута; проверка отказа TCP учитывает время ответа Windows.
- Внутренние имена в примерах заменены учебными. Установленное приложение и системные настройки не меняются при сборке.

macOS: Apple Silicon, 15+, ad hoc без notarization. Windows: встроенный Python, Npcap устанавливается отдельно. Проверки исходников не равнозначны аппаратной приёмке каждого компьютера. Обновление устанавливается вручную.
