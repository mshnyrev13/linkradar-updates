# Имитация первого запуска на Mac

20 октября 2026, тестовая версия 2.9.1. Публикация остаётся остановленной.

## Выполнено

Открыт отдельный экземпляр упакованного приложения с новым каталогом данных
через `--data-dir`. Существующая база, установленное приложение и фоновая
служба не изменялись. Обычное определение интерфейсов и LLDP включено;
ping, Stream, тест скорости и ручной захват сами не запускались.

В новой базе проверены нулевые количества строк в sessions, samples, hop_samples,
routes, events и session_data. Ключа service.key в профиле нет; подключения
к прежней службе нет. Процесс приложения продолжал работать после открытия.

22 проверки Mac startup прошли: отсутствие BPF, отмена авторизации, успешная
подготовка, необходимость повторного входа, отсутствие/недоступность службы,
запуск из DMG, защита пользовательских данных и установщика.
Это имитации с подменёнными командами; настоящий запрос администратора
и реальная установка компонентов при этих проверках не выполнялись.

## Границы

Пустой профиль не удаляет системную группу access_bpf, права /dev/bpf*,
Wireshark, задачи launchd и решения Gatekeeper. `--data-dir` намеренно
отключает автоматическую установку компонентов. Поэтому это проверка
чистого пользовательского состояния приложения, а не чистая macOS.

Для полной приёмки первой установки без Wireshark нужна чистая macOS
на отдельном компьютере или в виртуальной машине. Gatekeeper по-прежнему
отклоняет ad hoc сборку без Developer ID/нотаризации. Защита ОС не отключалась.

## Повторение

Замените путь к бинарнику на фактическое расположение тестового приложения:

```sh
test_profile=$(mktemp -d /private/tmp/network-watch-first-launch.XXXXXX)
"/path/to/LinkRadar.app/Contents/MacOS/LinkRadar" --data-dir "$test_profile"
```

При повторении создавайте новый каталог, чтобы снова получить пустую историю.
Для выхода закройте только тестовое окно; рабочий экземпляр не трогайте.
