# LinkRadar для Windows

## Установка

1. Откройте [Releases](https://github.com/mshnyrev13/linkradar-updates/releases/latest) и скачайте файл `LinkRadar-<версия>-Windows-x64-Setup.exe` для Windows 10/11 x64.
2. Запустите установщик. Он установит LinkRadar для текущего пользователя и добавит его в меню «Пуск». Ярлык на рабочем столе можно выбрать в мастере.
3. Запустите **LinkRadar**. Python и Qt уже в комплекте. Установщик без подписи Authenticode, поэтому Windows может показать предупреждение SmartScreen.

В выпусках с Windows ZIP распакуйте весь архив в одну папку и запустите `LinkRadar.exe`.

## Захват трафика и определение порта

Для захвата пакетов и приёма LLDP/CDP установите [Npcap](https://npcap.com/#download) отдельно. Затем выберите сетевой адаптер в LinkRadar. Объявление коммутатора обычно приходит в течение 30–60 секунд. Захват запускается отдельной кнопкой ▶.

Ping, маршрут, тест скорости и мониторинг OBS/vMix доступны без Npcap. Graphene требует корпоративного доступа.

## Обновление и удаление

Сохраните нужный отчёт через «Экспорт TXT», закройте LinkRadar и запустите новый `Setup.exe`. При переходе с ZIP можно удалить папку прежнего приложения после проверки новой установки.

Для удаления откройте «Параметры» → «Приложения» → LinkRadar. Файлы TXT, которые вы сохранили, остаются в выбранной папке.

## Фоновый движок

Установщик по умолчанию ставит только приложение. Если вам нужен фоновый движок, запустите «Установить или обновить фоновый движок» из группы LinkRadar в «Пуске» и подтвердите запрос администратора. Из старого ZIP используйте `Install background.cmd`.

После обновления приложения повторите эту команду, если фоновый движок уже установлен. Перед удалением LinkRadar выберите «Удалить фоновый движок» в «Пуске» или запустите `Remove background.cmd` из старого ZIP.
