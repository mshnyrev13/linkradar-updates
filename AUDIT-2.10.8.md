# LinkRadar 2.10.8 — аудит длинной истории и графиков

21.10.2026, поверх локальной 2.10.7. Пять исправительных циклов и затем
контрольный проход. [Журнал, команды и доказательства](https://github.com/mshnyrev13/vcs-network-watch).
Нагрузочные данные и иллюстрации синтетические. Установленная app, служба,
системные настройки, рабочие профили и GitHub не изменялись.

## Исправлено

1. Маршрут нового сервера без собственных измерений искался сканированием
   маршрутов других серверов/сессий. Добавлен индекс `(session,target,ts)`.
   Воспроизведение с 20 000 чужих маршрутов теперь проходит контроль объёма SQL.
2. Статистика узлов за 12 часов создавала временную группировку и читала всю
   таблицу. Существующий индекс узлов расширен покрывающими полями, без второго
   дублирующего индекса. Короткое окно использует индекс времени; окно от половины
   сохранённой сессии — покрывающий индекс. Миграция атомарна: при отказе создания
   новый индекс не заменяет старый. Измерения не переписываются и не удаляются.
3. Журнал заново форматировал и сортировал до 12 часов событий на каждом ping.
   При отсутствии новых/истёкших событий используется прежний список. Новые события,
   TTL и смена сессии обновляют журнал; прокрутка и выделение сохранены.
   Форматируются только новые/изменённые строки, кэш освобождает истёкшие записи.
   Большой префикс удаляется прямым выбором диапазона вместо обхода блоков Qt.
   Многострочные сообщения удаляются целиком; хвосты ошибок не остаются.
4. Частые переподключения/пропуски Stream отменяли прореживание графика: рисовались
   все исходные точки. Теперь сохраняются пики, крайние состояния и границы внутри
   каждого пикселя. Скрытый пропуск разрывает линию; ложной непрерывности нет.
   История, отчёты и точные значения под курсором не прореживаются.
5. При расчёте jitter и границ графика неизменившаяся строка адаптера больше
   многократно не разбирается. При смене адаптера/IP-источника разрыв сохраняется;
   формула jitter не менялась.

Одинаковые синтетические стенды, отдельные процессы. Медианы повторов;
для полного render массового TTL — один проход, отдельно есть трёхкратный
микрозамер операции удаления в log-expiry.json.

Короткие окна остаются единицами/десятками миллисекунд; разброс замеров есть.
12-часовой снимок всё ещё дорогой: около 0,5 с на этом компьютере, без гарантии
обновления каждые 0,5 с на любом Mac. Измерения движка продолжаются независимо.
Непрерывный Stream-график на этом стенде стал немного дороже: 17,628 → 23,513 мс;
это цена учёта границ, не скрытая регрессия в отчёте.

Запись 4000 циклов (60 000 проб узлов): медиана 0,895 → 0,886 мс, P99
1,738 → 1,805 мс; ускорение записи не заявляется. Выделенные страницы всей базы
6 414 336 → 6 926 336 байт (+8,0% на этом стенде). Индекс занимает больше места;
сроки хранения 12 ч, пакеты 120 с и очистка при закрытии сохранены.

## Проверено

- 377 тестов, 11 пропусков, без ошибок; 6 локальных integration; два JS-набора.
- Шесть больших снимков до/после совпали побайтно после исключения версии:
  короткий/длинный период, выбранный hop и исторический фокус.
- 60 seeded историй × 3 окна: 79 925 сверок native/legacy/TXT.
- 200 seeded графиков: 118 152 проверки extrema и отсутствия ложных линий.
- Атомарная миграция старого индекса, rollback при отказе, точные агрегаты
  mixed ok/timeout/error; error исключён из знаменателя потерь и RTT.
- Журнал: тихий такт, TTL, новая запись, сброс сессии, чтение и выделение.
- Восемь состояний на 900×640, 1100×760, 1440×960; повтор при 150% DPI.
  Изображения основных состояний и плотных разрывов — в журнале.

Завершающий совместный прогон и проверка готовой упаковки фиксируются в журнале
round6. Контроль ограничен доступной средой: Windows runtime, чистый Mac/новый
пользователь, физический USB/коммутатор, живые OBS/vMix и ночной soak в этом этапе
не проверены. Наличие Windows ZIP не означает его успешный запуск на Windows.
Условие остановки — отсутствие новых существенных находок в выполненном
контрольном проходе; возможные будущие улучшения не исключаются.


### Готовая app на macOS

Готовая 2.10.8 через Finder/LaunchServices прошла 7 этапов с ручным en0:
публичный IPv4 ya.ru, пауза/продолжение, en999 без fallback, возврат адаптера,
новая сессия по имени ya.ru, масштаб/экспорт/очистка. По 3 подтверждённых ответа
на обеих целях; это не тест шлюза. Отдельный packaged engine сохранил 5 проб
и паузу после SIGKILL, продолжение дало 8/8 ответов, remote GUI — 25/25.
Очистка после закрытия успешна. Исходные модули Mac/Windows совпали с checkout;
Windows runtime не проверен. Подпись ad hoc не заменяет Developer ID/notarization.


Финальный совместный synthetic-прогон: 119,77 с, CPU 6,46% одного ядра,
heartbeat P99 34,67 мс / max 66,84 мс. Записаны 54 207/54 207 строк Graphene,
ошибок I/O нет; буфер пакетов удержался в 32 МиБ. Закрытие очистило шесть
измерительных таблиц. Peak RSS 188 448 768 байт; короткий тест не заменяет
ночную проверку памяти. После пятого исправительного цикла контрольная матрица
не выявила новых существенных дефектов в доступных сценариях.
