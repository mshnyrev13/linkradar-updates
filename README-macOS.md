# LinkRadar 2.10.9 — macOS

Для macOS 15 и новее на Apple Silicon. Python и Qt входят в приложение.

## Установка и обновление

1. Закройте LinkRadar, если приложение открыто.
2. Откройте DMG и перенесите `LinkRadar.app` в `Applications`, заменив предыдущую версию при обновлении.
3. Запустите приложение из `Applications`.

При первом запуске из Applications приложение проверяет права BPF. Если их нет, macOS запросит пароль администратора для встроенного `install-capture-access-mac.command`. Wireshark устанавливать не нужно. Если доступ уже настроен, например Wireshark, повторного запроса для BPF нет. Проверка выполняется и при уже установленном фоновом движке.

Компонент добавляет только запускающего пользователя в стандартную группу `access_bpf` и устанавливает собственную системную задачу для прав `/dev/bpf*`. Она восстанавливает доступ после загрузки Mac и появления новых устройств. Интерфейс приложения не запускается от root. Если после установки доступ ещё не появился, выйдите из учётной записи и войдите снова либо перезагрузите Mac. При отмене подтверждения ping остаётся доступен, LLDP и захват могут быть недоступны; следующий запуск повторит проверку.

Установка фонового движка выполняется отдельно через встроенный `install-background-mac.command` и может вызвать ещё один запрос администратора. Последующие открытия проверяют версию и путь движка. Актуальная служба продолжает работать; устаревшая обновляется с системным запросом администратора и сохранением активной сессии/паузы.

Пояснения о размещении приложения и настройке доступа показаны строкой внутри главного окна. Отдельных информационных окон при старте нет. Системный запрос администратора остаётся только при фактической установке компонентов.

## Проверка macOS

Сборка подписана ad hoc, без Developer ID и нотарификации Apple. Проверка целостности подписи проходит, но Gatekeeper отклоняет такую скачанную сборку; на другом Mac возможно сообщение «повреждено». Это ограничение текущей поставки. Для распространения без этого ограничения нужны Developer ID и нотарификация; сертификата на машине сборки нет. Настройки безопасности автоматически не изменяются. Контрольные суммы файлов опубликованы в Release.

## Диагностика

В нижнем ряду слева — управление и показатели, по центру — маршрут, справа — jitter и задержка RTT. Ширину маршрута и графиков можно менять перетаскиванием разделителя.

- Вверху выберите сетевой адаптер. Switch, Port и VLAN появятся после LLDP; объявления часто приходят раз в 30–60 секунд.
- Введите сервер, выберите интервал и нажмите ▶ рядом с адресом. ⏸ сохраняет историю; ▶ продолжает сбор. Смена сервера с последующим запуском создаёт новую историю.
- Graphene читает метрики выбранного коммутатора и порта. Нужны корпоративная сеть/VPN и доступ к источнику.
- Кнопка «Тест» находится внизу левого столбца под показателями, в одной строке с результатом. Тест проверяет загрузку и отдачу по 15 секунд. Перед каждым направлением — 3 секунды прогрева. Заливка и процент общего прогресса находятся внутри кнопки; повторное нажатие отменяет тест.
- Copy копирует сетевые параметры; «Экспорт TXT» сохраняет данные сессии.

Выбранный вручную адаптер используется для ping и ICMP-маршрута. Смена адаптера переключает новые пробы без сброса истории и сохраняет паузу; запоздалые ответы предыдущего адаптера отбрасываются. При отключении выбранного адаптера показывается недоступность, перехода на Wi-Fi или другой маршрут нет. «Автоматически» использует маршрут ОС. Для ping и маршрута LLDP не нужен. HTTP-тест скорости привязан к выбранному адаптеру; в Auto используется маршрут ОС. DNS использует резолвер ОС.

## Хранение и очистка

Ping, hop-пробы, маршруты, события, сетевые параметры, точки Graphene и результаты скорости хранятся в SQLite за последние 12 часов. Старые записи удаляются автоматически, включая время паузы; сбор продолжается. При обычном закрытии приложения останавливается сбор, очищаются база, журнал событий, служебные логи и память захвата. Сохранённые вручную TXT-экспорты и настройки доступа к службе остаются. Экспорт включает только сохранённые на этот момент данные. При аварийном завершении обработчик закрытия не гарантируется.

## Захват пакетов

При открытии показана пустая таблица на пять строк, блок занимает минимальную высоту.

Отдельная панель расположена под Graphene. ▶ запускает захват на адаптере, выбранном вверху (LLDP для захвата не требуется), ⏸ приостанавливает, ■ завершает. Автоматического запуска нет. Доступ BPF настраивается при первом запуске из Applications с подтверждением администратора, как описано выше.

Хранятся первые 256 байт каждого кадра и его полная длина. История — только в памяти, не более 2 минут, включая время паузы. Есть дополнительные пределы: 50 000 кадров и оценка 32 МиБ. Клик по строке открывает hex/ASCII снимок. Перетащите разделитель под панелью вниз, чтобы увеличить таблицу.

При отключении USB выбор адаптера сохраняется, а захват останавливается. Оставшиеся строки обозначены «последние пакеты». После подключения дождитесь появления адаптера и нажмите ▶. Смена адаптера останавливает захват; повторный запуск — вручную. Для чужого трафика порта коммутатора требуется SPAN/mirror.

## Фоновый режим

Установленный фоновый движок обеспечивает системный сбор, пока сессия активна. При обычном закрытии окна сессия завершается и данные очищаются; служба остаётся установленной, но без активного мониторинга. Физический сон или выключение компьютера исключают отправку проб.

Для удаления службы откройте содержимое пакета приложения и запустите `Contents/Resources/packaging/remove-background-mac.command`. После замены приложения откройте LinkRadar из Applications. Версия 2.9.3 обновляет старую службу и путь запуска автоматически, если вы подтвердите запрос администратора. Измерения выполняются движком той же версии, что и окно; при отмене обновления приложение сообщает о проблеме и не запускает второй движок. Активная сессия, выбранный адаптер и пауза сохраняются; время перезапуска остаётся разрывом измерений. Если обновление прервалось, следующий запуск завершит восстановление по временному файлу состояния; файл удалится после успеха и не возобновляет сессии старше 12 часов.

## Компонент доступа BPF

В Finder нажмите правой кнопкой по `LinkRadar.app` → «Показать содержимое пакета». Скрипты находятся в `Contents/Resources/packaging`. Для ручной установки запустите оттуда `install-capture-access-mac.command`; рядом находится `bpf-access-root.sh`. Для удаления используйте `remove-capture-access-mac.command` из того же каталога. Удаление отдельно от фонового движка убирает только нашу задачу `/Library/LaunchDaemons/tech.vcs.network-watch.bpf.plist` и её helper `/Library/PrivilegedHelperTools/tech.vcs.network-watch.capture/bpf-access.sh`.

Общая группа `access_bpf` и членство пользователя сохраняются, чтобы не повредить настройку Wireshark и других средств захвата. Удаление helper не отзывает уже выданные права немедленно. После перезагрузки устройства BPF получают стандартные права ОС, если другой компонент не настраивает их заново. При следующем открытии Network Watch без доступа снова предложит настройку.

Чистая установка на Mac без Wireshark ещё требует проверки на отдельном компьютере. На машине разработки системные права и работающая служба для тестов не менялись.

На образе только приложение и ссылка на Applications. Скрипты находятся внутри приложения в `Contents/Resources/packaging`, инструкции — в `Contents/Resources/Documentation`. Автоматическая настройка использует встроенные скрипты.

## О приложении

Меню macOS «LinkRadar → О LinkRadar…» открывает отдельное окно: версия из движка, платформа, Python/Qt и ссылки на GitHub/встроенное руководство. В Windows пункт находится в меню «Справка». Окно открывается только по команде пользователя и не прерывает измерения.

## Как сделать распространение стабильнее

1. Подписывать Developer ID Application с Hardened Runtime, проходить нотарификацию Apple и stapling; проверять скачанный DMG с quarantine на чистой системе. Текущая подпись ad hoc этого не заменяет.
2. Выпускать и проверять отдельные arm64/Intel пакеты либо universal2 с универсальными Python/Qt. Сейчас пакет только Apple Silicon, macOS 15+. Понижение номера в Info.plist само по себе не добавляет поддержку старых macOS.
3. Предусмотреть одну первоначальную установку служебных компонентов вместо двух отдельных запросов, а после отказа — явный повтор по кнопке, без автоматического запроса при каждом открытии. Это предложение; текущая логика авторизации не изменена.
4. Службу, BPF и доступ к локальной сети проверять отдельно; ошибка дополнительной функции должна оставлять обычный ping доступным. Штатные запросы безопасности macOS нельзя полностью убрать кодом приложения.

Блоки окна подписаны «Сетевая идентификация», «Анализа сетевого трафика» и «Диагностики сети». Наведение на заголовок показывает назначение блока; адаптер локального захвата указан в подсказке кнопки ▶/⏸ и статуса.

Справа вверху рядом с Copy находится шестерёнка: «Журнал событий» (показать/скрыть), «Журнал ошибок» и «Экспорт TXT». Отдельных кнопок этих действий внизу больше нет. Измерение скорости — в одной строке внизу левого столбца диагностики.

Компактное окно: левый столбец 180 px, минимальный размер 900×640, начальный — до 1100×720 с учётом доступного экрана. При узком маршруте скрываются вспомогательные Count/Name; имя узла и число проб доступны по наведению на IP. Avg, Min, Cur, PL% и график Min–Max остаются видимыми. При расширении Count/Name возвращаются. Скорость внизу столбца запускается кнопкой «Тест», процент остаётся внутри неё.


## Ручной выбор адаптера — 2.9.2

Выберите Wi-Fi или USB-Ethernet вверху, введите IP/имя нужного устройства и нажмите ▶.
Ping и ICMP-маршрут привязаны к выбранному адаптеру и его исходному адресу;
при отключении или отсутствии пути перехода на другой адаптер нет.

Перед нативным ICMP комплект проверяет готовность сетевого доступа через
Network.framework на том же интерфейсе. Эта проверка не отправляет UDP-данные.
При необходимости macOS показывает обычный запрос «Локальная сеть» для LinkRadar:
подтвердите доступ. Пока macOS ожидает решение, ICMP-пробы не запускаются.
При отказе или недоступности показывается ошибка проверки с пояснением по наведению,
а не выдуманная задержка или скрытый переход в «Автоматически».

Права BPF для LLDP/захвата и разрешение macOS «Локальная сеть» — разные доступы.
Подпись пока ad hoc; Developer ID и нотарификация в эту версию не добавлены.
