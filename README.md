# LinkRadar

## Скачать приложение

**[Скачать последнюю версию для macOS и Windows →](https://github.com/mshnyrev13/linkradar-updates/releases/latest)**

- **macOS 15+ / Apple Silicon:** скачайте `.dmg` и перенесите LinkRadar в «Программы».
- **Windows x64:** скачайте `.zip`, распакуйте весь архив и запустите `LinkRadar.exe`.
- Отдельный Python не нужен. Для LLDP и захвата пакетов в Windows нужен Npcap.

## Как обновляться

1. Версии **2.10.5 и старше** один раз обновите вручную по ссылке выше.
2. Начиная с **2.10.6**, приложение проверяет новые версии при запуске и каждые 6 часов.
3. При новой версии появляется предложение «Скачать». Оно открывает публичную страницу выпуска без входа в GitHub.
4. Сохраните нужный TXT, закройте приложение и установите новый пакет. Автоматической замены программы нет.

При публикации стабильного Release с двумя установщиками и контрольными суммами GitHub Actions автоматически обновляет `latest.json`.

Этот репозиторий содержит установщики и канал обновлений. Исходники проекта и тесты хранятся в отдельном закрытом репозитории.
