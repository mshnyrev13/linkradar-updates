# LinkRadar

**[Скачать для macOS и Windows](https://github.com/mshnyrev13/linkradar-updates/releases/latest)** · [Инструкция](https://wiki.yandex-team.ru/hd/vcs/vcs-for-help/linkradar/) (корпоративный доступ)

Приложение для диагностики сети: ping, маршрут, задержки и потери, jitter, LLDP, графики порта из Graphene, тест скорости, ручной захват пакетов и мониторинг OBS/vMix.

Это единый публичный репозиторий: актуальные исходники, тесты, инструкции, выпуски и канал обновлений. История разработки до объединения сохранена в прежнем репозитории vcs-network-watch. В публичный код не включены рабочие базы, захваты, личная память и журналы реальных сетевых проверок.

## Установка

- **macOS 15+, Apple Silicon:** скачайте DMG, перенесите LinkRadar в «Программы». Подпись ad hoc; Developer ID и notarization пока отсутствуют.
- **Windows x64:** распакуйте весь ZIP и запустите LinkRadar.exe. Для LLDP и захвата отдельно установите Npcap.
- Python в готовых пакетах уже есть. Graphene требует корпоративного доступа; остальные сетевые функции работают независимо от Graphene.

## Начало работы

1. Выберите адаптер. При ручном выборе ping, маршрут и тест скорости используют его; отключение адаптера не переключает измерения на другой.
2. Введите сервер и нажмите ▶. ⏸ сохраняет историю; новый сервер начинает новую историю.
3. Захват пакетов запускается отдельной кнопкой ▶ и хранит только последние две минуты.
4. TXT-экспорт и журнал доступны через шестерёнку. При обычном закрытии измерения и служебные логи очищаются; сохранённые TXT остаются.

## Обновления

Приложение проверяет новые версии при запуске и каждые 6 часов. «Скачать» открывает страницу выпуска: установите новую версию вручную после сохранения нужного отчёта. Канал latest.json сохранил прежний адрес.
