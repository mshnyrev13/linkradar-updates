# LinkRadar

LinkRadar объединяет диагностику сети, тест скорости, захват пакетов и мониторинг трансляций OBS/vMix в одном окне.

## Скачать

Откройте [последний выпуск](https://github.com/mshnyrev13/linkradar-updates/releases/latest) и выберите файл для своей системы.

| Система | Что скачать и запустить |
| --- | --- |
| Windows 10/11 x64 | `LinkRadar-<версия>-Windows-x64-Setup.exe`. Запустите мастер, затем откройте LinkRadar в «Пуске». Если в выпуске есть только Windows ZIP, распакуйте весь архив и запустите `LinkRadar.exe`. |
| macOS 15+, Apple Silicon | `LinkRadar-<версия>-macOS-arm64.dmg`. Откройте образ и перенесите LinkRadar в «Программы». |

Python и Qt включены. Для захвата пакетов и LLDP/CDP на Windows нужен [Npcap](https://npcap.com/#download). Подробности в инструкциях для [Windows](docs/windows.md) и [macOS](docs/macos.md).

## Что можно проверить

- **Сеть.** Выберите адаптер, введите сервер и нажмите ▶. LinkRadar показывает ping, маршрут, потери, RTT и jitter. LLDP/CDP определяет коммутатор и порт, если от них приходят объявления. Graphene требует корпоративного доступа.
- **Скорость и трафик.** Запустите HTTP-тест скорости или отдельный захват пакетов. В захвате доступны последние две минуты.
- **Трансляция.** Откройте вкладку Stream и выберите OBS или vMix. Доступные показатели зависят от источника. [Настройка Stream](docs/stream.md)

Сохраните нужный отчёт через «Экспорт TXT» перед закрытием приложения. LinkRadar проверяет обновления и открывает страницу выпуска для установки вручную.
