# Проверка 2.9.1 перед публикацией

20 октября 2026. После проверки пользователь поручил добавить все нововведения
в GitHub. Готовится тестовый релиз 2.9.1 с известными ограничениями ниже.
Существующие v2.8.1 и pre-release v2.9.0 остаются без изменений.

## Уже проверено

- 190 автоматических тестов: OK, 11 пропусков по платформенным условиям.
- Mac arm64: сборка, strict codesign, запуск собственного окна с вкладками Сеть/Stream,
  штатное завершение в изолированном каталоге. Без установки служб и захвата.
- Windows ZIP: CRC, комплектность и точное совпадение всех корневых Python-модулей
  с общими исходниками. Runtime и launcher сохранены от прежней поставки.
- Startup-пояснения внутри главного окна, вместо информационных QMessageBox.

## Блокеры и ручная приёмка

| Сценарий | Критерий | Статус |
| --- | --- | --- |
| Скачанная Mac-сборка | Открывается на другом Mac | Блокер: Gatekeeper отклоняет ad hoc без Developer ID/нотаризации; сообщение со скриншота не устранено |
| BPF без Wireshark | Установка с авторизацией, повторный вход, LLDP приходит; отказ не отключает ping | Проверены фикстуры; чистый Mac не проверен |
| Windows 2.9.1 | LinkRadar.exe открывает обе вкладки без отдельного Python | Новый ZIP на Windows не запущен; прежний 2.9.0 проверялся отдельно |
| Ping и пауза | На паузе новые пробы не идут; продолжение сохраняет историю; смена сервера начинает новую | Автотесты пройдены; ручная приёмка на реальном канале нужна |
| Выбор адаптера | Ping/маршрут идут через выбранный адаптер; отключение USB не переводит на Wi-Fi | Автотесты пройдены; физическое переключение не проверено |
| Graphene | Правильный switch/port, обновление по источнику; отключение сохраняет последние данные | Прежние живые проверки есть; в общей сборке нужен рабочий порт и доступ |
| Пакеты | Только ручной запуск; пауза/стоп; 120 секунд истории; новый LLDP после переподключения | Фикстуры пройдены; живой захват общей сборки не запускался |
| Скорость | По 15 секунд измерения в обоих направлениях, прогресс/отмена | Автотесты пройдены; живой тест общей сборки не запускался |
| Stream | OBS/vMix только читаются; метрики, события, отчёт без секретов | Автотесты пройдены; новые Mac/Windows пакеты с реальным эфиром не проверены |
| Закрытие | Измерения очищаются, экспорт сохраняется; отдельный технический журнал по политике 2.9.0 | Автотесты пройдены; реальная установленная служба не перезапускалась |
