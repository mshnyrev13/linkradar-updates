# LinkRadar 2.10.9 — Windows

Для Windows 10/11 x64. Python и Qt входят в комплект.

## Установка и обновление

1. Закройте LinkRadar, если приложение открыто.
2. Распакуйте весь ZIP в постоянную папку. Сохраните вместе `LinkRadar.exe`, `app`, `runtime` и `packages`.
3. Запустите `LinkRadar.exe`. На панели задач отображается значок приложения.

Для LLDP и захвата пакетов нужен отдельно установленный Npcap и разрешение захвата. Wireshark не требуется. Без Npcap остальные функции приложения доступны, но LLDP и захват недоступны.

## Диагностика

В нижнем ряду слева — управление и показатели, по центру — маршрут, справа — jitter и задержка RTT. Ширину маршрута и графиков можно менять перетаскиванием разделителя.

- Вверху выберите сетевой адаптер и дождитесь LLDP для Switch, Port и VLAN. Объявления часто приходят раз в 30–60 секунд.
- Введите сервер, выберите интервал 0,5 / 1 / 2 секунды и нажмите ▶ рядом с адресом. ⏸ сохраняет историю; ▶ продолжает сбор. Смена сервера с последующим запуском создаёт новую историю.
- Graphene требует корпоративной сети/VPN и доступа к источнику.
- Кнопка «Тест» находится внизу левого столбца под показателями, в одной строке с результатом. Тест проверяет загрузку и отдачу по 15 секунд. Перед каждым направлением — 3 секунды прогрева. Заливка и процент общего прогресса находятся внутри кнопки; повторное нажатие отменяет тест.
- Copy копирует сетевые параметры; «Экспорт TXT» сохраняет данные сессии.
- «Журнал ошибок» в меню шестерёнки справа вверху открывает `errors.log`: технические сбои за 12 часов, без измерений и ключей; сохраняется после закрытия.

Выбранный вручную адаптер используется для ping и ICMP-маршрута. Смена адаптера переключает новые пробы без сброса истории и сохраняет паузу; запоздалые ответы предыдущего адаптера отбрасываются. При отключении выбранного адаптера показывается недоступность, перехода на Wi-Fi или другой маршрут нет. «Автоматически» использует маршрут ОС. Для ping и маршрута LLDP не нужен. HTTP-тест скорости привязан к выбранному адаптеру; в Auto используется маршрут ОС. DNS использует резолвер ОС.

## Вкладка Stream

Вкладка **Stream** → ▶: состояние трансляций OBS и vMix раз в секунду. OBS — WebSocket-сервер должен быть включён (Инструменты → Настройки сервера WebSocket); на этом компьютере пароль подставляется из настроек OBS. vMix — веб-API `http://127.0.0.1:8088/api`; для потерь кадров откройте окно vMix Statistics. Битрейт/RTT/ретрансмиты TCP-соединений (RTMP) доступны только при запуске приложения от администратора. Кнопки «Копировать» и «Сохранить TXT…» формируют отчёт для провайдера без ключей потоков. Ширина столбцов таблиц меняется перетаскиванием. Подробно: [STREAM.md](STREAM.md).

## Хранение и очистка

Ping, hop-пробы, маршруты, события, сетевые параметры, точки Graphene и результаты скорости хранятся в SQLite за последние 12 часов. Старые записи удаляются автоматически, включая время паузы; сбор продолжается. При обычном закрытии приложения останавливается сбор, очищаются база, журнал событий, служебные логи и память захвата. Сохранённые вручную TXT-экспорты и настройки доступа к службе остаются. Экспорт включает только сохранённые на этот момент данные. При аварийном завершении обработчик закрытия не гарантируется.

## Захват пакетов

При открытии показана пустая таблица на пять строк, блок занимает минимальную высоту.

Панель находится под Graphene. Отдельная ▶ запускает захват на адаптере, выбранном вверху (LLDP для захвата не требуется), ⏸ приостанавливает, ■ завершает. Захват автоматически не запускается.

История хранится только в памяти, максимум 2 минуты, включая время паузы. Сохраняется до 256 байт кадра, максимум 50 000 кадров и оценка 32 МиБ. Клик по строке открывает hex/ASCII снимок. Перетащите разделитель под панелью вниз, чтобы увеличить таблицу.

При отключении USB захват останавливается, выбранный адаптер сохраняется. Старые строки помечены «последние пакеты». После подключения дождитесь появления адаптера и нажмите ▶. Смена адаптера останавливает захват; повторный запуск — вручную. Для всего трафика порта коммутатора требуется SPAN/mirror.

## Фоновый режим

Для установки системного движка запустите `Install background.cmd` из распакованной папки и подтвердите запрос администратора. Для удаления используйте `Remove background.cmd`. Данные службы хранятся в `%ProgramData%\VCS Network Watch\<id>` с доступом только для SYSTEM и администраторов; окно получает их через защищённый канал (подробно — STANDALONE.md).

При обновлении установленного фонового движка повторно запустите `Install background.cmd` из нового комплекта: это перезапускает движок. Версия 2.9.0 требует новый движок (данные в ProgramData, capability `session_data`); при обновлении с 2.8.1 и раньше `Install background.cmd` снимает прежнюю задачу и файлы. К старому движку интерфейс не подключится. При обычном закрытии окна сбор останавливается, данные очищаются; служба остаётся установленной без активного мониторинга. Во время физического сна или выключения сетевые пробы не выполняются.

## О приложении

Шестерёнка «⚙ → О LinkRadar…»: версия, платформа, версии Python/Qt и ссылки на проект/руководство. Диалог открывается только пользователем и закрывается вместе с основным окном. Отдельная строка меню не занимает высоту компактного окна.

Блоки окна подписаны «Сетевая идентификация», «Анализа сетевого трафика» и «Диагностики сети». Наведение на заголовок показывает назначение блока; адаптер локального захвата указан в подсказке кнопки ▶/⏸ и статуса.

Справа вверху рядом с Copy находится шестерёнка: «Журнал событий» (показать/скрыть), «Журнал ошибок» и «Экспорт TXT». Отдельных кнопок этих действий внизу больше нет. Измерение скорости — в одной строке внизу левого столбца диагностики.

Компактное окно: левый столбец 180 px, минимальный размер 900×640, начальный — до 1100×720 с учётом доступного экрана. При узком маршруте скрываются вспомогательные Count/Name; имя узла и число проб доступны по наведению на IP. Avg, Min, Cur, PL% и график Min–Max остаются видимыми. При расширении Count/Name возвращаются. Скорость внизу столбца запускается кнопкой «Тест», процент остаётся внутри неё.

Проверка безопасности 2.10.1: см. [SECURITY-AUDIT.md](SECURITY-AUDIT.md). Обновлена certifi и усилены установщики/IPC; запуск Windows остаётся отдельной приёмкой.

Визуальный/кодовый аудит 2.10.3: [AUDIT-2.10.3.md](AUDIT-2.10.3.md). Исправлены заполнение длинных графиков и шкалы; перерисовка использует ограниченный кэш, точные hover-данные сохранены.

Аудит точности 2.10.4: [AUDIT-2.10.4.md](AUDIT-2.10.4.md). Графики сохраняют extrema RTT/jitter и последнюю пробу; Stream считает скорость потерь по фактическому интервалу.
