# LinkRadar 2.9.1

Общая тестовая версия для macOS и Windows. Прежнее название — VCS Network Watch.
Исходники Windows-ветки Stream объединены с настройкой доступа к захвату на Mac
и новым компактным интерфейсом. Python и Qt входят в готовые пакеты.

## Что изменилось

- Название LinkRadar, единое оформление окна, значков, экспортов и пакетов.
- Компактное окно от 900×640: сетевые параметры слева, Graphene справа;
  управление и показатели диагностики слева, маршрут по центру, jitter/RTT справа.
  При сужении маршрута скрываются Count/Name, подробности доступны по наведению.
- Скорость — кнопка «Тест» внизу левого столбца с общим прогрессом;
  по 15 секунд загрузки/отдачи и по 3 секунды прогрева.
- Шестерёнка справа вверху: журнал событий, журнал ошибок и экспорт сессии в TXT.
- Ручной захват на адаптере, выбранном вверху; для локального захвата LLDP не нужен.
  Доступны запуск, пауза и стоп; смена/отключение адаптера останавливает захват.
  История только в RAM, максимум 120 секунд; переподключение не запускает её само.
- Окно «О приложении» с версией и вкладкой «Руководство», без имён создателей.
- Собственная настройка доступа BPF на Mac без установленного Wireshark:
  запрос администратора только при необходимости. Скрипты и инструкции внутри .app;
  в DMG только приложение и ссылка Applications.
- Вкладка Stream из Windows 2.9.0: чтение OBS/vMix, графики, события и отчёт
  без ключей потоков. Сохранены ProgramData/защищённый IPC службы Windows,
  восстановление потоков измерений и технический журнал ошибок.
- Сохранены привязка ping/маршрута к адаптеру, пуск/пауза с историей,
  12-часовое хранение измерений и очистка при обычном закрытии.

## Скачать и запустить

| Файл | Назначение |
| --- | --- |
| `LinkRadar-2.9.1-macOS-arm64.dmg` | Apple Silicon, macOS 15+; перенести LinkRadar.app в Applications |
| `LinkRadar-2.9.1-Windows-x64.zip` | Windows 10/11 x64; распаковать весь архив и запустить LinkRadar.exe |
| `LinkRadar-2.9.1-source.zip` | Общие исходники, тесты, инструкции, память проекта и учебные картинки |
| `SHA256SUMS.txt` | SHA-256 трёх файлов поставки |

[Инструкция с картинками](https://wiki.yandex-team.ru/users/mshnyrev/linkradar/)
(внутренняя Wiki). Для Graphene нужны корпоративная сеть/VPN и доступ к источнику.
Для LLDP и захвата на Windows отдельно установите Npcap; Wireshark не требуется.
На Mac для LLDP/захвата нужен доступ BPF.

При установленной фоновой службе Windows повторно выполните `Install background.cmd`
из нового комплекта. На Mac после замены приложения с установленной службой нужна
перезагрузка. Сохраните нужный TXT до закрытия старого окна: обычное закрытие
очищает измерения. Технический журнал ошибок хранится отдельно до 12 часов.

## Проверка и ограничения

- На Mac: 190 автоматических тестов, 11 платформенных пропусков, без ошибок.
- Windows ZIP: CRC, точное совпадение всех 24 Python-модулей с исходниками,
  скриптов, значков и документации; все 2723 файла runtime/packages сохранены.
  Новая сборка 2.9.1 на Windows не запускалась; результаты 2.9.0 её не заменяют.
- Mac: сборка arm64, strict codesign и изолированный запуск. Подпись ad hoc,
  без Developer ID и нотарификации: Gatekeeper может блокировать скачанное приложение.
  Intel Mac не поддерживается этим DMG. Windows без Authenticode.
- Чистый Mac без Wireshark, реальный LLDP/захват и установка/миграция системной
  службы новой версии требуют отдельной ручной проверки.
- ICMP jitter не равен jitter видео; timeout промежуточного узла не доказывает
  потерю транзитного трафика. Тест скорости и DNS используют маршрут ОС.
  Физический сон/выключение останавливают сетевые пробы.
