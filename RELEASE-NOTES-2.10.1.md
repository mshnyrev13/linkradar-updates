# LinkRadar 2.10.1 — исправления безопасности

- Обновлена certifi до 2026.10.19: устранён затронутый CA-набор GHSA-6q48-6c7w-9gw2.
- Mac installer фиксирует сценарий до авторизации; root создаёт только заданную пользовательскую конфигурацию. Стандартные потоки launchd направлены в /dev/null.
- Усилены Windows UAC, ACL и операции с деревом файлов службы; требуется натурная приёмка Windows.
- IPC ограничивает полный кадр по размеру/времени и поддерживает отмену. JSON не заменяется pickle.
- Закрыты утечка ключа в первом RTMP path segment, неоднозначные сетевые структуры, опасные XML-объявления и зависание HTTP при медленной передаче байтов.
- Зафиксированы транзитивные зависимости и CI actions; добавлены воспроизводимые проверки безопасности.

Настройки и история не мигрируются и не удаляются этим архивом. Новая сборка
не заменяет уже работающий движок сама по себе: после согласованной установки
потребуется штатное обновление службы с системным подтверждением.

Сборки локальные, не опубликованы. Mac arm64/macOS 15+, ad hoc без нотарификации.
Windows ZIP не исполнялся на Windows. Полный отчёт — SECURITY-AUDIT.md.
